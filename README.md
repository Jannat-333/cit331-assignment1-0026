Club name:

The reading room-The university book club

Description:

Our club is for people who enjoy reading and telling stories, who have interest in poetry and listening to people talk and for people who have a passion of litracy.In our club we host book discussion, debates, poetry competitions and much more.

Pages

1.Home (index.html) 
2.Events (events.html) 
3.Register (register.html)


 How to Run Locally

1. Download the repository to your computer.
2. Open the project in Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Open index.html in VS Code.
5. Right-click inside the HTML file and select Open with Live Server.
6. The website will open in your default web browser.
7. Use the navigation menu to visit the Home, Events, and Register pages.
